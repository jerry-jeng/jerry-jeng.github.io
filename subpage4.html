ℹ 部署說明

本系統為純前端單一 HTML 檔案，直接上傳至 GitHub Repository 即可透過 GitHub Pages 訪問。
資料儲存於瀏覽器 localStorage，不會上傳至任何伺服器。
API Key 僅存於本機瀏覽器，由瀏覽器直接呼叫 Claude API（需注意 CORS 政策）。

GitHub Pages 部署步驟：
1. 建立 GitHub Repository → 上傳 index.html
2. Settings → Pages → Source: main branch
3. 訪問 https://<username>.github.io/<repo>
